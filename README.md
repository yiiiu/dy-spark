# 抖音续火花助手（Douyin Spark Keeper）

一个**自托管**的抖音"续火花"全自动助手：可部署在你的 Windows 个人电脑或 Linux 云服务器上，每天定时自动给指定好友发送一条私信或分享一条抖音视频，维持聊天火花（🔥）长久不熄。

提供基于 **Vue 3 + Element Plus + Lucide 矢量图标** 打造的现代化双栏工作台，原生支持**浅色 / 深色（Dark Mode）**模式平滑切换。支持 **文本私信** 与 **抖音视频转发** 双模式续火花。日常运行**完全无人值守**——只需在登录态过期时重新扫码上传一次。

> ⚠️ 仅限本人账号、少量好友、每天一条的**个人自用**场景。自动化发私信违反抖音社区公约，存在被风控、限流甚至封号的风险，使用后果自负。请勿用于批量营销、多账号运营或对外提供服务。

## 功能特性

- 🖥️ **现代化双栏工作台**：左侧 340px 常驻调度控制中心（倒计时、指标统计、立即发送、干跑模拟）+ 右侧多任务工作区，自适应紧凑排版，彻底消除长滚动
- 🌙 **原生深浅色主题切换**：支持浅色模式与深色模式（Dark Mode）一键平滑切换，状态本地持久化记忆
- 🔥 **专属矢量火花徽章与智能筛选**：专属红橙黄三色流光矢量火花徽章，智能识别火花天数与状态，提供「一键勾选火花好友」与「只看火花好友」筛选
- 🎬 **视频转发中心**：支持从抖音最近点赞中自动拾取视频链接或手动粘贴视频链接，多视频待发队列轮播分发，支持视频模式与文本模式灵活切换
- ⚡ **完善的跨平台运维体系**：
  - **Windows**：双击 `start.bat` 一键启动并自动唤起浏览器，双击 `stop.bat` 一键精准停止
  - **Linux**：提供 `./start.sh` 与 `./stop.sh` 脚本，支持 systemd 服务托管
  - **进程生命周期管理**：自动记录 `data/app.pid`，双重校验避免端口冲突与残留
- 🛡️ **智能防错发与风控熔断**：
  - **会话切换校验**：点击联系人后校验右侧会话标题，确认目标昵称才发送，杜绝错发
  - **搜索兜底**：列表点不到时自动调用搜索框直达会话
  - **真实发送校验**：文字离开输入框才算成功，失败自动重试
  - **当日自动补发**：本轮有失败时约 45 分钟后只对失败者自动补发一次
  - **限流熔断**：识别"操作频繁 / 安全验证"提示立即停止本轮，防止触发风控
- ⏱️ **节奏拟人化**：发送时间具备随机时间抖动窗口、好友之间具备随机秒级间隔、文案从模板库随机抽取
- 💡 **轻量低功耗**：1 核 1G 内存的轻量云服务器即可流畅运行（部署脚本自动配置 2G swap）

## 工作原理

```text
你的电脑（一次性扫码导出）            本地或云服务器（日常全自动）
┌───────────────────────────┐      ┌──────────────────────────────────────────────┐
│ extract_cookie.py         │      │ FastAPI Web 服务（现代双栏 UI / 深浅色主题）   │
│ 打开浏览器 → 手机扫码登录  │ 上传 │ APScheduler：每天定时触发                     │
│ 导出登录态 state.json     │ ───▶ │ Playwright 无头浏览器                         │
└───────────────────────────┘      │ 打开 douyin.com/chat                          │
                                   │ 模式 1：给勾选好友发送随机文本                │
                                   │ 模式 2：轮播转发队列中的抖音视频              │
                                   │ 校验发送结果 / 失败自动补发                   │
                                   │ 实时日志终端，掉线高亮标红                   │
                                   └──────────────────────────────────────────────┘
```

> **安全提示**：登录态在**本机扫码获取、服务器只复用**，避免"机房 IP + 异地登录"触发风控；网页端消息与视频分享同样计入抖音火花。

```text

├── stop.sh                    # Linux 一键暂停/停止脚本（安全终止与端口释放）
├── core/
│   ├── automation.py          # Playwright 自动化发送 / 点赞抓取 / 列表读取
│   ├── scheduler.py           # 每日定时与当日补发调度中心
│   ├── config.py              # 配置读写（好友名单、视频队列、定时参数）
│   └── runtime.py             # 状态、实时日志流与运行历史记录
├── static/
│   ├── index.html             # 现代化双栏前端（Vue 3 + Element Plus 本地化单页）
│   └── vendor/                # 本地化第三方静态依赖（无需外网 CDN 即可访问）
├── deploy/
│   ├── deploy.sh              # Debian / Ubuntu 一键部署脚本
│   └── douyin-spark.service   # systemd 系统服务单元配置
└── data/                      # 运行时自动生成（已 gitignore）
    ├── config.json            # 业务运行配置
    ├── state.json             # 抖音登录凭证
    ├── app.pid                # 当前运行进程 PID
    └── logs/                  # 运行时日志
```

## 快速开始

### 第一步：获取登录态（在你的 Windows/macOS 电脑上）

在拥有图形界面的电脑上安装依赖并提取登录态：

```bash
pip install -r requirements.txt
playwright install chromium
python extract_cookie.py
```

弹出的浏览器窗口里用手机抖音 App 扫码登录，登录成功后脚本会自动在 `data/state.json` 导出登录凭证。

---

### 第二步：启动与运行

你可以根据使用场景，选择在**本地电脑**或**云服务器**运行：

#### 方式 A：本地电脑运行（Windows）
- **启动服务**：直接双击运行根目录下的 [`start.bat`](start.bat) 即可。脚本会自动检查 Python 环境、读取 `.env` 端口配置并在后台拉起 Web 服务，服务就绪后自动在默认浏览器中打开控制台。若服务已在运行，将直接为您打开控制台页面。
- **暂停 / 停止**：双击运行根目录下的 [`stop.bat`](stop.bat)，脚本将依据 PID 及端口占用精准安全终止服务并释放端口资源。

#### 方式 B：Linux 服务器部署（Debian 13 / Ubuntu）
把整个项目目录上传到服务器（如 `/opt/douyin-spark`），然后以 root 执行：

```bash
sudo bash deploy/deploy.sh
```

脚本会自动完成：安装依赖、安装 Chromium、创建 2G swap、设置上海时区、生成随机访问令牌、注册 systemd 服务并启动。完成后会输出访问地址和令牌（保存在项目根目录 `.env`）。

日常通过快捷脚本管理：
- 启动：`./start.sh`
- 暂停：`./stop.sh`

---

### 第三步：网页配置使用

1. 在浏览器打开控制台地址（如本地 `http://127.0.0.1:18101` 或服务器 `http://服务器IP:8000`），输入部署或 `.env` 中生成的访问令牌（`AUTH_TOKEN`）；
2. **上传登录凭据**：在左侧控制中心上传第一步生成的 `data/state.json`；
3. **好友名单管理**：进入「好友与消息」选项卡，点击「获取聊天列表」读取好友，可使用「只看火花好友」过滤，勾选需要续火花的好友并保存；
4. **视频转发配置（可选）**：如需使用视频转发续火花，进入「视频转发中心」选项卡，开启视频转发开关，点击「从最近点赞抓取」或手动粘贴分享链接添加至待发队列；
5. **定时与调度设置**：进入「定时设置」选项卡设置每天发送时间（默认 21:00）及时间抖动范围；
6. **模拟与验证**：先在左侧控制台点击「干跑模拟」验证流程，确认无误后点击「立即发送」或等待每日定时触发。

之后每日全自动运行。唯一的人工介入时机：网页顶部状态标红提示"登录态已过期"时，重新执行第一步扫码并上传即可。

## 快捷运维脚本说明

| 脚本文件 | 适用平台 | 功能说明 |
| :--- | :--- | :--- |
| `start.bat` | Windows | 双击一键启动。自动检测 Python、读取 `.env` 端口、后台静默拉起、循环探测服务就绪后自动在浏览器打开控制台 |
| `stop.bat` | Windows | 双击一键暂停。优先读取 `data/app.pid` 精准终止，兜底探测端口监听进程（过滤 PID 0），彻底释放端口并清理 PID |
| `start.sh` | Linux | 优先检测并启动已注册的 systemd 服务；未注册时采用 `nohup` 后台启动并记录 PID |
| `stop.sh` | Linux | 优先调用 `systemctl stop` 停止系统服务；兜底采用 `kill` 和 `fuser -k` 释放端口 |

## 部署进阶：域名 + HTTPS

如果你的域名已解析到服务器（假设为 `douyin.example.com`）：

```bash
apt-get install -y nginx certbot python3-certbot-nginx

cat > /etc/nginx/sites-available/douyin-spark <<'EOF'
server {
    listen 80;
    server_name douyin.example.com;
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }
}
EOF

ln -sf /etc/nginx/sites-available/douyin-spark /etc/nginx/sites-enabled/douyin-spark
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

certbot --nginx -d douyin.example.com --non-interactive --agree-tos \
  --register-unsafely-without-email --redirect
```

并在 `.env` 中追加 `HOST=127.0.0.1`（让后端只监听本机、由 nginx 转发），然后执行 `systemctl restart douyin-spark`。

## 自动发送策略与保护机制

- **会话标题校验**：点击联系人后，必须确认右侧会话顶部标题出现目标昵称，才继续发送，杜绝"发给上一个人"。
- **搜索兜底**：列表点不到（懒加载/名字不在最近聊天）时，自动用搜索框查找并点击「发消息」直接打开会话。
- **发送状态校验**：文字进入输入框 → 按 Enter → 文字离开输入框，三步均满足才判定发送成功；失败自动重试一次。
- **当日智能补发**：本轮存在失败好友时，约 45 分钟后只对失败者自动补发一次；若期间一轮全部成功，补发自动取消。
- **限流熔断保护**：检测到"操作频繁 / 安全验证"等提示立即停止本轮，防止连续操作触发更严厉风控。
- **拟人化节奏控制**：发送时间带有随机抖动窗口、好友之间设有随机间隔秒数、文本从模板库随机抽取、视频队列自动轮转推进。

## 常见问题 FAQ

- **状态显示"登录态已过期"**：
  本机重新运行 `extract_cookie.py` 扫码，并在网页端重新上传 `state.json` 即可。登录态通常可维持数天至数周。
- **如何切换深色 / 浅色主题？**：
  点击网页右上角的「浅色/深色主题」切换按钮，系统会即时切换视觉风格并记住您的偏好。
- **如何修改运行端口？**：
  在项目根目录下的 `.env` 文件中修改或添加 `PORT=你的端口号`（例如 `PORT=18101`），重启服务即可。
- **好友切换失败**：
  优先点击「获取聊天列表」勾选（获取的是聊天列表中真实的显示名称）；若手动输入，请务必填写完整的备注或昵称。
- **提示操作频繁**：
  适当调大「定时设置」中的好友间隔秒数、减少单次发送人数；少量好友（几个到十几个）运行最为稳妥。
- **服务器 IP 被风控**：
  建议优先选择与日常登录城市相同的国内机房节点；海外机房 IP 相对更容易触发平台安全滑块或验证码。
- **网页打不开**：
  请确认安全组或本地防火墙已放行相应端口，并确认服务正常处于运行状态。
